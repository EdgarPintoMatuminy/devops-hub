📝 Uso Básico de vi y view

vi es el editor de texto clásico de Unix/Linux. view es su versión de solo lectura (ideal para revisar logs y configuraciones sin riesgo de modificarlas).

🚀 Abrir Archivos

Bash 
# Abrir archivo con vi (edición)
vi /etc/httpd/conf/httpd.conf

# Abrir archivo con view (solo lectura, seguro)
view /etc/httpd/conf/httpd.conf

# Abrir en modo solo lectura con vi (alternativa)
vi -R /etc/httpd/conf/httpd.conf

# Abrir en modo "mejorado" (vim)
vim /etc/httpd/conf/httpd.conf

⌨️ Modos de vi

📌 Los 3 modos principales:
• Modo Normal (Comandos): Modo por defecto al abrir vi. Permite navegar, borrar, copiar.
• Modo Inserción: Para escribir texto. Se entra con i, a o o.
• Modo Línea de Comandos: Para guardar, salir, buscar. Se entra con : (desde modo normal).

🔑 Comandos Esenciales

vi - Comandos Básicos 
# ENTRAR en modo inserción (desde modo normal)
i          # Insertar antes del cursor
a          # Insertar después del cursor
o          # Insertar nueva línea debajo
O          # Insertar nueva línea encima

# VOLVER a modo normal (SIEMPRE pulsar primero)
Esc        # Vuelve al modo normal desde cualquier modo

# GUARDAR y SALIR (en modo línea de comandos, pulsar : primero)
:w         # Guardar (write)
:q         # Salir (quit)
:wq        # Guardar y salir
:x         # Guardar y salir (alternativa)
:q!        # Salir SIN guardar (forzado)
:w!        # Forzar guardado (si el archivo es de solo lectura y tienes permisos)

# NAVEGACIÓN (en modo normal)
h j k l    # Izquierda, abajo, arriba, derecha
gg         # Ir al principio del archivo
G          # Ir al final del archivo
:n         # Ir a la línea número n (ej: :42)
Ctrl+f     # Avanzar una página
Ctrl+b     # Retroceder una página

# BUSCAR (en modo normal)
/patron    # Buscar hacia adelante (ej: /error)
?patron    # Buscar hacia atrás
n          # Ir a la siguiente coincidencia
N          # Ir a la coincidencia anterior

# BORRAR (en modo normal)
x          # Borrar carácter bajo el cursor
dd         # Borrar línea completa
dw         # Borrar palabra
d$         # Borrar hasta el final de la línea

🛡️ view - El vi Seguro

⚠️ Regla de oro: Cuando solo necesitas leer un archivo de configuración o log, usa siempre view en lugar de vi. Así evitas modificaciones accidentales en producción.
Bash 
# Revisar configuración de Apache de forma segura
view /etc/httpd/conf/httpd.conf

# Revisar logs con navegación cómoda
view /var/log/httpd/error_log

# Ver configuración de WebLogic sin riesgo
view /dominio/E01_PRU_WL122_OSB_INTER/config/config.xml

# Buscar dentro del archivo ya abierto con view
/Error         # Busca "Error" hacia adelante
/proxywl       # Busca configuración de proxy
:n             # Ir a línea específica

# Salir de view (igual que vi)
:q

💡 Trucos Útiles para el Día a Día

vi/vim - Trucos 
# Mostrar números de línea (muy útil para referenciar)
:set number
:set nonumber        # Para quitarlos

# Reemplazar texto en todo el archivo
:%s/antiguo/nuevo/g           # En todo el archivo
:%s/antiguo/nuevo/gc          # Con confirmación línea a línea
:s/antiguo/nuevo/g            # Solo en la línea actual

# Copiar y pegar (en modo normal)
yy         # Copiar (yank) línea actual
3yy        # Copiar 3 líneas
p          # Pegar debajo
P          # Pegar encima

# Deshacer y rehacer
u          # Deshacer último cambio
Ctrl+r     # Rehacer

# Abrir otro archivo desde dentro de vi
:e /ruta/otro/archivo.conf

# Dividir pantalla (vertical/horizontal)
Ctrl+w v   # Dividir verticalmente
Ctrl+w h   # Dividir horizontalmente
Ctrl+w w   # Cambiar entre paneles

🆘 Salir de vi cuando estás "atrapado"

🚨 Si no sabes cómo salir de vi:
1. Pulsa Esc (varias veces por si acaso)
2. Escribe :q! y pulsa Enter
Esto te sacará sin guardar cambios, pase lo que pase.

🌐 WebLogic: Administración y Parcheo

🛠️ Procedimiento de Parcheo (SPBAT)

⚠️ Pre-requisito: Asegurar que el FS de /oracle tenga espacio suficiente (ej. ampliar de 10G a 20G). Ver con: df -h /oracle/
Bash 
# 1. Backup: Realizar snapshot de la máquina virtual (Manual)

# 2. Parar procesos Java
/dominio/E01_PRU_WL122_OSB_INTER/custombin/stopE01_PRU_WL122_OSB_INTER_SVC111.sh
/dominio/E01_PRU_WL122_OSB_INTER/custombin/stopAdminServer.sh
sudo systemctl stop nodemanager
# (Repetir para otros nodos, ej. SVC121)

# 3. Rollback de parches conflictivos (si aplica, ej. 32720458)
/oracle/fmw/OPatch/opatch rollback -id 32720458 -silent

# 4. Aplicar parche con SPBAT
cd /coredumps
unzip p39221243_122140_Generic.zip
cd SOA_SPB_12.2.1.4.260417/tools/spbat/generic/SPBAT
./spbat.sh -phase precheck -oracle_home /oracle/fmw
./spbat.sh -phase apply -oracle_home /oracle/fmw

# 5. Arrancar procesos Java
sudo systemctl start nodemanager
/dominio/E01_PRU_WL122_OSB_INTER/custombin/startAdminServer.sh
/dominio/E01_PRU_WL122_OSB_INTER/custombin/startE01_PRU_WL122_OSB_INTER_SVC111.sh

📋 Plantillas de Resolución de INCs

Copia y adapta estas plantillas para tus respuestas en el sistema de tickets.

✅ URL carga correctamente (No se reproduce el error)
"Se ha revisado la infraestructura y se ha verificado que el Apache, las instancias de WebLogic y la aplicación se encuentran en buen estado. La siguiente URL carga correctamente y responde sin problemas: [INSERTAR URL]. Por lo tanto, no parece tratarse de un problema de la aplicación. Se recomienda revisar los permisos de acceso y las reglas del firewall como posible origen de la incidencia."
🔄 Reinicio de Servicios / Instancias (Alta Memoria/Swap)
"La alerta fue recuperada tras realizar un reinicio ordenado de las instancias/servicios que consumían mayor cantidad de memoria, liberando los recursos asociados y optimizando el uso de swap. Estas acciones estabilizaron el sistema, permitiendo su correcto funcionamiento."
📬 Metaposta (Atasco de paquetes)
"Se revisa la infraestructura de Metaposta y se detectan instancias en estado warning. De manera preventiva, se realiza un reinicio completo de todos los dominios, seguido del reinicio de la aplicación en el servidor correspondiente. Tras el reinicio, los paquetes atascados comienzan a publicarse correctamente. Se confirma: instancias OK, despliegues OK, colas JMS OK y datasources (DS) OK."
📉 Filesystem (Llenado de Logs)
"[GERTU_WEB] Se comprimen los logs antiguos que más memoria ocupaban. Estado actual del FS verificado y liberado."
